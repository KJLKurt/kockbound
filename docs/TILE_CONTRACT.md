# Shared support tiles and platform remover

Version boundary: simulation/protocol/content 0.5.0. The arena is a protected central disk at configured minimumRadius plus four radial rows of 24 numbered sectors. shared/content/tiles.ts defines the layout and support lookup without a rendering dependency. World.tiles records warnAt/fallAt by registered tile ID. Snapshot validation rejects unknown/core IDs and warning intervals shorter than twenty ticks.

Shrink retains the nominal radius as a bot/navigation hint, but authoritative support comes from intact tiles. When a row's outer extent exceeds the shrinking target, blocks warn in gold for at least one second, then fall in six staggered groups over the next half second. Loss of support is checked within every movement substep, preventing a dash from skipping a removed sector. All same-tick eliminations retain the shared outcome contract. The protected central disk remains until timeout. This intentionally changes some seeded match outcomes from the previous continuous disk.

Platform remover: registered independently toggled item, twenty-second held lifetime, one successful use. Fire/Remove chooses the first removable tile along accepted aim at three, four, five or six metres. Core, already warned and off-board targets are skipped; no valid tile retains the item. A marked tile remains supported for twenty ticks, then disappears. Drops preserve expiry. Bots use ordinary inputs, steer away from warned/current gaps and avoid unsafe dash routes. Helicopter chooses an unwarned supported tile toward the inner arena, falling back to core. Ground pickups on removed support disappear.

Presentation: game renders individually extruded blocks with the original crown/paving texture, blue side walls, tiny decorative seam grooves, golden warning material and falling motion. Geometry comes from the same layout; decorative seam widths are not gameplay gaps. Reduced motion retains static warning and removes fallen tiles immediately. Terminal frames continue falling visuals. Lobby retains the detailed original intact island. Old full-platform scale shrinking is removed during play.

This contract supports the next independent random tile/sky-rock/wind hazards and mystery crate/additional danger work; those are not implemented by this increment. Rendering remains separate from collision. Physical phone, human traversal/remover aiming and performance/audio approval remain open.
